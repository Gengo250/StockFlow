# StockFlow v0.1.0-beta

Primeira versão empacotada do StockFlow como aplicativo desktop. É uma prévia
da interface: a camada visual está navegável, as camadas de domínio,
aplicação e persistência ainda não existem.

## O que vem nesta versão

- executável único para **Linux x64**, sem necessidade de Python instalado;
- janela principal com menu lateral (Dashboard, Estoque, Vendas, Produtos,
  Relatórios, Configurações);
- tela de **Estoque** e formulário de **Novo produto** com o layout aprovado;
- demais telas exibem o placeholder "em breve".

## Como usar

```bash
chmod +x StockFlow-0.1.0-linux-x64
./StockFlow-0.1.0-linux-x64
```

O primeiro frame demora alguns segundos: por ser arquivo único, o conteúdo é
descompactado numa pasta temporária a cada execução.

## Limitações conhecidas

- **Nada é persistido.** Não há banco de dados; o que for digitado se perde ao
  fechar o app.
- O Dashboard abre em branco de propósito — a tela ainda não foi construída.
- Só o build Linux x64 foi gerado e validado. A receita
  (`packaging/stockflow.spec`) já contempla Windows, mas o `.exe` ainda não
  foi publicado.
- O binário não é assinado.
